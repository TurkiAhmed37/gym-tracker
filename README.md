# Gym Tracker

موقع شخصي لتسجيل تمارين الحديد ومتابعة الفوليوم الأسبوعي لكل عضلة.

## الاستخدام اليومي
1. افتح الموقع من أيقونته على الشاشة الرئيسية.
2. من **Log**، اضغط اليوم (Upper A أو Legs 1 أو غيرها).
3. لكل سيت: اكتب الوزن والتكرار واضغط ✓.
   - الأرقام الرمادية الباهتة هي أرقام آخر مرة. لو بتكررها، اضغط ✓ مباشرة.
4. اضغط **Finish workout** لما تخلص.

**الوزن:** اكتب الوزن الكلي. دمبلين 12 تكتبها 24.

**بدون نت:** سجّل عادي. النقطة فوق تصير رمادية (Offline)، والبيانات تتزامن لحالها أول ما يرجع النت.

## الصفحات
| الصفحة | وش فيها |
|---|---|
| Log | تبدأ تمرين، أو تكمل تمرين مفتوح |
| Dashboard | الفوليوم الأسبوعي لكل عضلة (سيتات أو كيلو)، والتمارين حسب اليوم، ورسم لكل الأسابيع، وتقدم أي تمرين. وتعلّم منها أسبوع الديلود |
| History | كل التمارين السابقة. تضغط أي تمرين عشان تعدله أو تحذفه |
| Program | تعدل الأيام والتمارين والسيتات والتكرارات والسوبرست، وتشوف الفوليوم المخطط |
| Settings | الصورة واللون، ونطاق الهدف، والنسخ الاحتياطي، وتسجيل الخروج |

## طريقة الحساب
- **السيت المحسوب:** سيت فيه علامة ✓ وتكرار واحد على الأقل.
- **العضلة الأساسية:** السيت يُحسب لها سيت كامل.
- **العضلة المساعدة:** السيت يُحسب لها **نص سيت** (نفس قاعدة ملف الخطة).
- **الحمل:** الوزن × التكرار. العضلة المساعدة تاخذ نص الحمل.
- **الأسبوع:** يبدأ يوم الأحد.
- **الهدف:** من 10 إلى 20 سيت لكل عضلة، وتقدر تغيره من Settings.

## النسخ الاحتياطي
- **Settings ← Download backup (JSON):** ملف فيه كل بياناتك. احفظه في iCloud أو Google Drive.
- **Download sets as spreadsheet (CSV):** يفتح في Excel.
- **Restore from backup:** يرجّع البيانات من ملف JSON، ويستبدل البيانات الحالية بعد ما تأكد.
- الموقع يذكرك كل 30 يوم بتنزيل نسخة.

## الصيانة (بدون برمجة)
- **تعديل البرنامج:** كله من صفحة Program، وما تحتاج تلمس الكود.
- **التمارين القديمة:** لو غيرت تمرين أو حذفته، التمارين اللي سجلتها قبل تبقى زي ما هي.
- **رفع تحديث للكود:**
  1. عدّل الملف في GitHub.
  2. في `sw.js`، غيّر `VERSION` (مثلاً من `v1` إلى `v2`).
  3. التحديث يوصل جوالك ثاني مرة تفتح الموقع.
- **إعدادات Firebase** موجودة في `firebase-config.js`. هذي الإعدادات مو سرية.
- **قواعد الأمان** موجودة في `firestore.rules`، ونفسها لازم تكون ملصوقة في Firebase Console ← Firestore ← Rules. هي اللي تمنع أي أحد غيرك يشوف بياناتك.

## الملفات
```
index.html, styles.css      الصفحة والتصميم
js/app.js                   التشغيل وتسجيل الدخول والتنقل
js/store.js                 الحفظ (Firebase)
js/calc.js                  كل الحسابات (فوليوم، أرقام، نسخ احتياطي)
js/seed.js                  البرنامج الأصلي من ملف الخطة
js/log.js, dash.js, program.js, settings.js   الصفحات
sw.js, manifest.webmanifest يشتغل بدون نت وينزل كتطبيق
vendor/firebase/            مكتبة Firebase 12.19.0 (محفوظة داخل الموقع، فما تعتمد على أي رابط خارجي)
tests/calc.test.mjs         اختبارات الحسابات: node --test tests/calc.test.mjs
```

## هيكل البيانات في Firestore
```
users/{uid}/meta/program     الأيام والتمارين
users/{uid}/meta/settings    الهدف، أسابيع الديلود، اللون، آخر نسخة احتياطية
users/{uid}/meta/profile     الصورة
users/{uid}/sessions/{id}    كل تمرين: التاريخ، اليوم، وكل تمرين مع عضلاته وسيتاته
```
كل جلسة تحفظ اسم التمرين وعضلاته وقت التسجيل، عشان التاريخ ما يتغير لو عدلت البرنامج بعدين.
